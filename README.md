# Car-World Revival

Website für Car-World, eine Kfz-Meisterwerkstatt in Bad Neuenahr-Ahrweiler (Heimersheim). Gebaut mit TanStack Start, React und TailwindCSS, mit einem eigenen Admin-Bereich und einer Neon-Postgres-Datenbank.

## Development

Node.js und npm werden benötigt.

```sh
git clone https://github.com/3ytasarim/car-world-revival.git
cd car-world-revival
npm i
npm run dev
```
